For Video Express, I’d treat every generation as a **two-stage shot**:

**Prompt A = create the locked starting image/keyframe.**
**Prompt B = animate that exact image into the video shot.**

The biggest rule is **do not redesign the character in the video prompt**. The image establishes Strawberry, Broccoli, etc. The video prompt should primarily describe movement, performance, camera, atmosphere, and what must remain unchanged.

Below is the **60-second trailer generation package**, broken into short clips that we stitch together.

## One important Video Express workflow

**Generate the character image once and preserve it.** Once we get **the Strawberry we love**, don't keep asking Video Express to reinvent Strawberry from text. Use that approved Strawberry reference image wherever the platform allows image/reference input. Do the same with Watermelon, Broccoli, Corn, etc.

That gives us a pipeline:

**Character sheet → approved character reference → scene image prompt → approved keyframe → video prompt → clip → stitch.**

And for the eventual **8-minute episodes**, I'd use exactly this same system. Each episode becomes perhaps **40–70 controlled generations** rather than asking an AI to somehow maintain an eight-minute movie in one shot.

The result should give us much better continuity—and it means **Claude 5.5 and Video Express can work from the exact same locked Angry Fruit production bible.**
